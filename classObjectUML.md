# SG4 - Understanding Classes and Objects
## Class Name: Eyeglassess
## Class Description: All Eyeglassess come in different Shapes, Sizes, Frame types, and 'Grade"
## Properties: 
| Property | Data Type | Description |
|---|---|---|
| Rim Type | string | The Eyeglasses' Rim Type (e.g Full Rim, Half Rim, Semi Rimless, Rimless) |
| Frame Shape | string | The Eyeglasses Frame Shape (e.g Round, Oval, Rectamgular, Cateye, Aviators) |
| Size  | int | The Lens and Bridge width, and Temple Length of the Eyeglasses  |
| Grade | int | The "Grade" of the Eyeglasses' lens |
| Material | string | Type of Material used for the Eyeglasses' frame |
## Methods
| Method | Description |
|---|---|| | |
| Wear | Wear the Eyeglasses| 
| Clean | Clean the Eyeglasses| 
| Donate | Donate the Eyeglasses|

## Design Explanation
### Why did you choose this class?: I chose this class because I didn't know what to pick, and then when I looked at the reflection of the Monitors Screen I saw my Eyeglasses
### Which property is the most important? Why?: The most important property is, "Grade" because that's what's used to help aid the wearers eyes
### Which method is the most useful? Why?" The most useful method is, "Wear" because you need to wear the glasses for it to actually aid your eyes
